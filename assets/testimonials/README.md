# Testimonial headshots

Optional. Drop them here and the cards swap the initials monogram for the photo:

```
daniel-pelkowitz.jpg    julian-remba.jpg    jacques-fouche.jpg
```

Square, 128x128 minimum (shown at 52px), under 30KB, head and shoulders on a
plain background. Until a file exists the card shows the person's initials,
which is a deliberate fallback rather than a placeholder to be embarrassed by.

Unlike the demo chat avatars, these are photographs of real people giving real
testimonials, so real headshots are correct here — with their permission.
